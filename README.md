# ATM Simulator

A simple ATM Simulator developed using Python.

## Project Overview

This project simulates basic ATM operations using Python.
It allows users to perform common banking operations through
a command-line interface.

## Features

- User authentication
- Check account balance
- Deposit money
- Withdraw money
- Exit the application

## Technologies Used

- Python
- Object-Oriented Programming
- Conditional Statements
- Loops
- Functions

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/vijayhariharanbk/atm-simulator.git
```

2. Navigate to the project folder:

```
cd atm-simulator
```

3. Run the Python program:
 ```
python atm_simulator.py
```
